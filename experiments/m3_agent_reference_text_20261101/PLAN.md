# M3-Agent 原始文本控制协议补充对照

这是 **QA-only 控制器对照**，不重新生成媒体、感知或记忆，也不替换原生工具版答案。
它读取 `m3_agent_matched_20261101` 从原始视频新建的同一份 M3 记忆。

## 原因与预先固定的解释

原生工具迁移版已观察到部分题在轮数上限前持续 Search、未提交答案。
这不能直接解释为参考记忆图能力差。参考源码实际使用文本
`Action: [Search]/[Answer]`，最后一轮明确要求 Answer，并允许合理猜测。
因此补充原协议控制器，分别报告两种结果，**不选取两者中较高的单题或整体分数**。
本组是在看到控制器完成率问题后设置的诊断，不是独立留出评测。

## 实现与固定条件

- 从冻结的 `m3_agent/control.py` 提取原样的 `system_prompt`、`instruction`、
  `pattern` 和 `consumer`；不运行 vLLM 权重初始化。
- 用相同 MiniMax-M3.1-Flash、adaptive/medium、8192 输出预算执行文本响应。
- 对齐当前实验为 6 轮、180 秒循环预算；这区别于参考默认的 5 轮和 1024 输出。
- 完整保留参考的末轮 Answer/合理猜测指令。它与原生工具版的证据约束提示不同，
  因此该结果是控制协议组合对照，不是仅改变一行代码的单变量结论。
- 与原生工具版共享同一份 memory JSON、身份更新和 BGE 嵌入缓存，
  每题仍按同一 current_clip 截止范围重建前缀图，不把未来语义强化带进历史问题。
- 所有 65 题运行同一控制器；问答失败计零；同一 MiniMax 评委/评分提示，
  不根据已有 gold 或先前评分修改预测。

## 产物

- `status.json`：执行状态。
- `model-usage.jsonl`：本组独立请求元数据；不计入首轮端到端记忆生成成本。
- `summary.json`：65 题整体评分。
- 原始逐题结果位于 `runs/m3_agent_reference_text_20261101/`。
- 原生工具版、原协议文本版、oGMemory 固定答案的共同评委结果将分列，
  不能把原协议文本版的有效答案率提高等同于准确率提高。
