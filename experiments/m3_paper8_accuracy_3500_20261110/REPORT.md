# 三视频较大后续证据预算对照

在 `study_23`、`kitchen_01`、`bedroom_05` 上复用八视频从头实验生成的记忆和索引，仅将每轮后续新证据的增量预算从 2,000 提高到 3,500 token；初始预算保持 3,500，不启用歧义保护。对全部 39 题重答，原答案和候选答案随机混合后统一盲评，失败计零。

| 指标 | 原方案 | 后续预算 3,500 |
| --- | ---: | ---: |
| 平均得分（0、0.5、1） | 39.74% | 48.72% |
| QA 模型 token | 1,382,454 | 1,451,420 |
| QA 失败题数 | 2 | 0 |
| study_23 得分 | 57.14% | 75.00% |
| kitchen_01 得分 | 30.77% | 34.62% |
| bedroom_05 得分 | 29.17% | 33.33% |

得分提高 8.97 个百分点，QA token 增加 4.99%；返回调用都有 usage。评委、embedding 和建记忆 token 不包含在 QA token 中。逐题为 7 题提高、2 题下降、30 题持平；其中 `study_23_Q12` 从汽车型号纠正为 Paul，旧答案为 0、新答案为 1。

原、新问答阶段墙钟时间之和分别约 15.26 和 21.13 分钟；运行窗口、服务状态及并发环境不同，不能把时间差严格归因于预算。题目级配对 bootstrap 的探索性 95% 区间约为 0 至 +19.23 个百分点，未考虑同视频题目相关性；这三个视频也是在发现失分后选定的。不能凭单次结果断言在其他视频上保分，更不能解释建记忆 token 的变化。

原始答案、逐题盲评、运行状态和 token 记录见 `baseline/`、`judgments.jsonl`、`status.json` 和 `usage-candidate-*.jsonl`。对剩余五个视频的独立扩展运行位于 `experiments/m3_paper8_accuracy_3500_holdout_20261110/`。
