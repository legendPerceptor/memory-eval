# 八视频后续证据预算对照

复用 `runs/m3_paper8_fresh_20261110` 的记忆、图和索引，不重新建忆。候选仅将问答时每轮后续新证据的增量预算从 2,000 提高到 3,500 token；首轮预算均为 3,500，不启用歧义提示。先在失分后选出的三个视频上试验，再对此前未包含的五个视频做扩展验证。每批原答案与候选答案混合盲评，评委按题给 0、0.5 或 1 分，失败计零。

## 分批汇总

| 数据集 | 题数 | 原方案得分 | 候选得分 | 原方案 QA token | 候选 QA token | 失败题数（原→候选） |

八视频平均得分下降 1.03 个百分点，QA token 增加 264,915（7.48%）；11 题提高、10 题下降、76 题相同。两个批次分别盲评，合计是分层汇总，并非将全部答案放在同一批统一盲评。题级配对 bootstrap 的探索性 95% 区间约为 −8.25 至 +5.67 个百分点，未考虑同一视频内题目的相关性。以上为平均得分，不是二元准确率；QA token 不包含评委、本地 embedding 或建忆 token，调用均返回 usage。

例如，`bedroom_04_Q02` 问以前喜欢的演员，原答案得 1、候选得 0；`study_05_Q07` 问制作叶子的步骤，原答案得 1、候选表示无法确定而得 0。另有近义答案得到不同分数的情况，例如 `study_09_Q10`。这些现象值得检查时间线、检索证据和评委一致性，但目前没有证据证明个别变化由预算本身造成。

结论：扩大后续证据预算未通过留出集验证，八视频汇总也未恢复得分且增加了问答 token，不应作为已验证优化部署。该试验没有重建记忆，不能据此推断建忆时间或 token 的变化。首批详情见 `experiments/m3_paper8_accuracy_3500_20261110/REPORT.md`；留出集原始答案、逐题评判、运行状态和用量记录位于本目录。
