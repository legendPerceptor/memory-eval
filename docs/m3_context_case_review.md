# A组初步错误审查（2026-11-01）

本页基于A恢复后的独立评分及原固定答案的前次共同评分。
不同评委批次可能引入波动；最终交错共同评分应以实验汇总为准。
本页不把“分数下降”直接归因于预算裁剪，也不根据金标给检索写特例。

## 1. 超时恢复不等于所有题都答对

原6道超时题现均有有效回答。初次评分中5题为1分：
study_05_Q07、study_05_Q11、gym_03_Q03、bedroom_04_Q05、bedroom_04_Q10。
study_05_Q12（剪刀使用次数）仍为0分，表明计数推理/事件合并问题没有随
运行稳定性恢复而自动解决。

本批比较：48题评分不变，8题提高，9题降低；A有32个满分、8个半分、25个零分。
均分接近基线，但内部存在明显得失，不能只给一个总体分数就宣布验收。

## 2. 区分不同失败机制

### 人物归属：gym_03_Q04

A答案同时提到了“total beginner”和“fitness is literally your job”，
却把训练者与教练角色混到Alice身上，给出“身体素质好”的结论。
这不是“完全没见到新手证据”的简单召回失败。
需要审查说话人与被称呼对象的绑定、跨片段身份信息，而不是只扩大top-k。

### 物体混淆与计数：gym_03_Q02

A把热身用的弹力带与后面戴在手臂/腰部的支撑护具放进同一条位置变化链，
得到三次，而参考答案为两次。它暴露的是物体区分和动作计数口径问题；
多取几个含“band”的片段可能反而增加混淆。

### 原答案的正确猜测不一定有充分证据：study_18_Q07

旧答案给出“第二层”，但自身承认检索材料没有明确层数；
A则回答证据不足。分数从1变0不自动证明某个明确“第二层”事实被压掉了，
还需检查原视频/源记忆是否实际保存该信息。不能通过要求模型猜测层数来
伪装记忆质量提升。

### 相近的错误答案也可能得到不同半分：study_05_Q06

旧、新答案都把书包描述为放在桌面，而参考答案是桌子左侧。
旧答案半分、新答案零分，本身不能支持明确的架构因果结论。
这也是需要交错共同重评、保留原评分的原因。

### 缺失精确空间关系：kitchen_20_Q09、study_18_Q10

“upper shelf”不能自动推成精确层数；“在工作桌上”也不等于“在桌上的笔筒里”。
应分别核查源记忆是否保存层数/容器关系、检索是否返回、预算视图是否保留、
模型是否正确使用。仅看最终错误答案，无法区分这四层。

### 谨慎程度和benchmark评分的差异：kitchen_20_Q12

A提到了白色带盖容器，却没有把它断言为实际被丢入的垃圾桶；
旧答案直接作了这个对应。自动评分下降可能混合了证据强弱判断与参考答案
匹配问题，不能直接解读为文本压缩丢失了“有盖子”这一字段。

## 3. 下一步的优先级

1. 完成B/C/D及共同评分，量化预算/格式改变的实际质量和用量取舍。
2. 对明确回归案例做源证据核对，避免把评委波动或正确猜测误当成检索问题。
3. 继续研究可追溯的人物/物体事实索引和前缀稳定的增量上下文；
   不把当前整视频拼接节点当作已经实现了M3-Agent式语义记忆。
4. 原视频信息未写入记忆时，文本上下文优化无法补回视觉细节；
   更完整采帧/按需重看应作为另一个受控实验，而不是混入本次固定记忆消融。
