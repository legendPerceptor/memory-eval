# M3：片段重试与显式不完整记忆继续执行

## 背景

一次完整视频实验中，84 个片段有 83 个成功；另一个片段的响应是人物/实体片段，
被情景记忆校验器正确拒绝。旧流程因此停止索引与问答，导致整段视频的 14 题缺失。
解决方式不能是接受错误 JSON、编造空记忆，或悄悄使用上轮旧记忆。

## 两层处理

### 1. 有上限的无效输出重试

`m3.episodic_memory --invalid-output-retries N` 只重试情景记忆域校验器明确标记的
`Invalid episodic memory:` 输出，N 范围为 0–2。
输入、提示、模型、预算和校验器均不改变。
HTTP 鉴权/参数错误、数据库错误不因包含类似字符串就变成格式重试。
既有 HTTP 过载/超时重试仍有自己的预算，两者不互相重置。

独立 driver 默认 N=0 保留历史行为；完整 pipeline 显式设为 1。
成功后的输出记录 `generation_retry_counts`，summary 的 `recovered_retries`
统计成功请求实际使用的额外尝试次数。耗尽的失败仍保留诊断、返回非零。

### 2. 有条件继续下游

完整 pipeline 的推荐配置：

```yaml
- id: episodic_memory
  type: m3.episodic_memory
  params:
    max_frames: 16
    invalid_output_retries: 1
    failure_policy: continue
    min_clip_coverage: 0.95
```

没有显式配置时 `failure_policy=stop`，便于复现旧的严格流程。
`continue` 不是忽略所有异常。必须同时满足：

- 至少有一个成功片段，成功比例达到阈值；
- 账号、视频、manifest、成功/失败集合和计数一致，没有重复或遗漏；
- 成功记录确实对应当前图中 completed 的情景节点，正文与回执一致；
- 失败属于可识别的片段输出、瞬时服务错误、截断或缺帧问题；
- 每个失败片段在图中**不存在旧情景节点**。

最后一项是刻意保守的安全边界：强刷失败时旧的 completed 节点可能仍在，
向量、转写或邻居检索可能把它重新带入上下文。这种情况继续失败关闭，
不会自动删除历史数据，也不假装已实现通用的旧证据隔离。
鉴权、数据库写入、不明错误、全失败或低覆盖仍停止下游。

## 状态、问答与续跑契约

- 允许继续时，episodic stage 为 `ok=True / status=degraded`，
  保留失败列表，并设置 `counts.partial_memory=1`。
- 只对成功产物创建记忆、建立索引；继续执行问答。
- 生成 `memory_coverage.json`，绑定账号、视频、数据库指纹及情景输出哈希，
  包含缺失片段 ID 和覆盖计数；连接指纹仅使用非秘密路由字段，不保存凭据或凭据的哈希。
- QA 会把缺失片段明确加入系统提示，并在每题输出中保存 `memory_coverage`。
  提示要求不能把证据缺失当作事实不存在，也不能将检索条数当成完整事件计数。
- 一条基于不完整记忆的非空答案仍可被评分，但**不能作为完整续跑凭据**：
  QA resume、阶段 probe、批量驱动不会把它当成永久完成而跳过修复。
- 只要仍有部分记忆缺失，单视频 CLI 最终返回 2；问答失败或协议无效也返回 2。
  非零表示“不完整”，不再意味着没有执行后续分析。普通非失败 warning 不改变退出码。
- 不重新抽样、不减少评测分母、不从多次答案中择优。统计时同时报告答案质量与记忆覆盖。

## 手动定向恢复

现有 `--retry-failed` 仍可使用。保留同一账号、输入和失败回执，
只强制失败片段；其他片段校验证据后复用。不要为补一个片段强刷全部感知与记忆。
独立对照实验仍应使用独立数据库；仅更换账号不能隔离所有历史片段主键。

## 验证边界

测试涵盖：格式重试上限、鉴权/存储错误不重试、准确覆盖集合、拒绝旧节点混入、
账号/数据库/manifest 绑定、下游 index/QA 继续、提示披露缺失、非零退出、
部分答案不被当作完整续跑结果。

另有实验工作区中的真实 SQL 故障注入验证：克隆首轮数据库，强制片段 52
两次输出无效，复用其余 83 条，实际索引 83 条，QA 使用 stub 回答检查完整链路。
它验证控制流和来源回执，**不是新的模型质量成绩**，也没有调用真实记忆/问答模型。

本改动不声称覆盖所有上游媒体处理故障，不保证缺少关键片段时答案仍正确。
证据不足应如实表现为低分/无法回答；覆盖率阈值不是质量保证。
